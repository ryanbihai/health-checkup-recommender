# 📝 话术与输出模板

> 本文件包含所有话术模板和输出规范，供 AI 在实际对话中使用。

---

## 第一阶段：信息收集话术

### 开场白

```
您好，我是您的专属体检顾问。请告诉我：
① 给自己还是给家人？
② 年龄和性别？
```

### 标准询问

1. "给自己还是给家人？"
2. "年龄和性别？"
3. "有没有特别想检查的部位或症状？"
4. "家族有没有心血管病、糖尿病/血糖病家族史？"
5. "之前体检有没有已知的异常？"

### 收集信息时

根据缺失信息发送对应问题

### 分析评估时

发送分析内容（基于 risk_logic_table.json 和 symptom_mapping.json）

## 第二阶段：推荐输出模板

### 风险评估输出

```
【风险评估】{年龄段}岁{性别}，Top3 高发风险：
① {风险1} ② {风险2} ③ {风险3}

{family_history_note}
```

示例：
```
【风险评估】50岁男性，Top3 高发风险：
① 心血管疾病 ② 肺癌 ③ 胃癌

注意：您有高血压家族史，心血管疾病风险提高
```

---

### 推荐套餐输出

```
【推荐套餐】（共 {N} 项，含必选 item029）

  item029 常规检查  ¥{price}
  {其他项目...}

【加项】➕ {itemID} {名称} ¥{price}
   适用原因：{依据}

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
💰 套餐总价：¥{total}（来自 calculate_prices.js 输出）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⚠️ 免责声明：本公司产品和服务仅供参考，不能替代专业医生的诊断。如有异常指标，请及时就医。
```

### 价格显示规范（强制）

- **每个项目价格**：来自 `calculate_prices.js` 输出
- **套餐总价**：必须使用 `calculate_prices.js` 计算，禁止手动计算
- **价格必须精确**：调用脚本获取真实数据

### 底价规则

**⚠️ ¥600 最低消费**：服务商要求套餐不低于 ¥600

- 若推荐总价不足 ¥600
- 自动根据用户画像补充高风险相关项目
- 优先补充：心血管、肿瘤筛查等项目

### 项目选择限制

> ⚠️ **数据库中没有胃镜、肠镜项目**
>
> 如用户有相关需求，只能推荐：
> - 胃功能项目（item016/item154）
> - 腹部彩超（item032）
> - 并说明原因

> ⚠️ **item029 为必选**
>
> 每个套餐必须包含常规检查（身高+体重+血压），自动加入无需询问

## 数据文件说明

### 唯一可信来源

| 文件 | 用途 |
|------|------|
| `reference/checkup_items.json` | 体检项目清单（含价格） |
| `reference/risk_logic_table.json` | 年龄性别风险评估 |
| `reference/symptom_mapping.json` | 症状→加项映射 |
| `reference/evidence_mappings_2025.json` | 循证依据 |

### 查询顺序

1. **风险评估**：先查 `risk_logic_table.json`
2. **症状匹配**：查 `symptom_mapping.json`（含同义词）
3. **加项依据**：查 `evidence_mappings_2025.json`
4. **项目价格**：查 `checkup_items.json`
5. **计算总价**：调用 `calculate_prices.js`

## 常见问题处理

### 用户提到胃镜/肠镜

```
抱歉，本数据库暂不包含胃镜、肠镜项目。
建议您：
- 胃部不适：选择胃功能3项（item016）或胃功能全项（item154）
- 腹部不适：选择腹部彩超（item032）

这些项目可以初步筛查胃癌风险。如有不适，建议到医院专科就诊。
```

### 用户问价格

```
套餐价格会根据所选项目自动计算。
参考价格范围：
- 基础套餐（5-6项）：约 ¥200-400
- 标准套餐（8-10项）：约 ¥500-800
- 全面套餐（12+项）：约 ¥1000+

具体价格以医院实际收费为准。
```

### 用户问能否用医保

```
体检套餐通常不属于医保报销范围，需自费支付。
但部分项目（如血常规、尿常规）在医院就诊时可走医保。
建议提前咨询体检机构。
```

## 注意事项

1. **禁止编造项目**：只能推荐 `checkup_items.json` 中存在的项目
2. **禁止手动计算**：所有价格必须通过 `calculate_prices.js` 获取
3. **必须获取同意**：发送二维码前必须询问用户
4. **保护隐私**：不读取本地文件，所有信息通过对话收集
