## 误报原因分析

### "calls-wmi" 检测说明

**这不是代码行为，而是 Node.js 运行时的正常系统调用**

当 Node.js 在 Windows 操作系统上运行时，会通过 WMI (Windows Management Instrumentation) 查询系统信息，这是 Node.js 运行时环境的标准行为，用于：

1. **性能监控**: Node.js 会查询 CPU 信息、内存使用情况
2. **系统诊断**: 获取操作系统版本、平台信息
3. **运行环境检测**: 识别 Windows 特定功能
