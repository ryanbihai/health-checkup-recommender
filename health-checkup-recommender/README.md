## ✨ 功能特色

| Feature | Description |
|---------|-------------|
| 🤖 智能推荐 | 根据年龄/性别/症状/家族史推荐体检项目 |
| 📋 循证依据 | 每项推荐附带医学证据 |
| ✅ 项目核查 | 代码验证确保项目真实存在 |
| 💰 价格计算 | 代码自动计算总价，避免LLM数学错误 |
| 📱 预约二维码 | 自动生成体检预约二维码（支持接口降级） |
| 🛡️ 容错降级 | 接口404时自动降级为默认二维码，确保100%成功率 |
| 🏥 机构对接 | 支持多家体检机构预约 |

---

## 安装

```bash
openclaw skills install health-checkup-recommender
```

## 使用

对你的 OpenClaw 说"我想做体检"或"推荐个体检套餐"即可启动。
